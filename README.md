## 📖 About the Project

TapBack is an individual mobile development project created as part of the Smart Mobile Development semester at Fontys University of Applied Sciences.

The project addresses a sustainability challenge in the festival industry: reducing disposable cup waste without making the festival experience less convenient.

The proposed solution combines a mobile application, NFC festival wristbands, and reusable cup return stations.

---

## 🎯 Project Objectives

- Improve convenience during festival payments.
- Encourage the use and return of reusable cups.
- Introduce a digital festival wallet concept.
- Explore NFC technology for festival interactions.
- Support a more sustainable festival experience.

---

## ✨ Planned Features

### 👤 User Accounts
- User registration and login
- Personal account management
- Access to individual wallet information

### 💳 Festival Wallet
- Festival balance overview
- Cashless payment concept
- Transaction history
- Wallet top-up functionality

### ♻️ Reusable Cup System
- Cup deposits during purchases
- Cup return through dedicated stations
- Deposit refund workflow
- Integration with NFC-based interactions

> These features represent the intended application scope. Implementation is ongoing.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android emulator or physical device

### Clone the Repository

```bash
git clone https://github.com/barreirafds/TapBack.git
cd TapBack
```

### Install Dependencies

```bash
flutter pub get
```

### Check the Development Environment

```bash
flutter doctor
```

### Run the Application

```bash
flutter run
```

### Run Tests

```bash
flutter test
```
